# Northstar Field Services Dataset

Run `python -m app.seed --reset` from `backend` to create the fictional company pack in `sample_documents/northstar_field_services/` and its matching database records.

The pack contains 20 active organizational documents, 10 obsolete document versions, and 10 adversarial prompt-injection documents. The database seed creates 10 job roles and 160 source-grounded requirements, including 80 mandatory requirements.
